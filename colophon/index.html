How this site is built, and what it deliberately does not do.

This site practices what it preaches.

Built with#

  • Hugo, a static site generator. There is no server-side code, no database and no admin panel to attack.
  • A hand-written theme called Redacted. Type is set in Source Serif 4 and JetBrains Mono, both under the SIL Open Font License.
  • Deployed with GitHub Actions to GitHub Pages.

What it does not do#

  • No trackers, no analytics, no cookies.
  • No third-party requests. Fonts, styles and scripts are served from this origin.
  • No inline scripts or styles. Every script is a separate file from this origin, and each has one job:
    • a small theme toggle;
    • search, built on Pagefind. The index is generated at build time and searched in your browser, so your queries never leave it;
    • one script per tool. The tools run entirely in your browser and make no network requests: a token or vector you paste in stays on your machine.

Hardening#

  • A strict Content Security Policy: default-src 'none', with script-src, style-src and font-src limited to 'self'. The one addition is 'wasm-unsafe-eval', which search needs to compile its WebAssembly module. It does not allow JavaScript eval.
  • The stylesheet and every script are fingerprinted and loaded with Subresource Integrity (sha384).
  • A security.txt (RFC 9116) for reporting vulnerabilities.

Labels you’ll see#

Posts carry a TLP label (Traffic Light Protocol 2.0). Everything published here is TLP:CLEAR or TLP:GREEN by nature, but the label tells you how the source material was originally shared. Advisories also show a severity and, where available, a CVSS score.
