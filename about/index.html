Security engineer. Former software developer.

I’m synt0x, a security engineer who spent the first part of my career as a software developer.

For years I built software: I designed it, wrote it, shipped it under deadlines and kept it running in production. Now I break it and help fix it. Knowing how software is actually built helps on both sides of that work: I know where to look for the weak spots, and I know what a fix has to look like for a development team to adopt it. I aim for findings that lead to real fixes, not findings that only look good in a report.

What you’ll find here#

  • Writing: writeups, deep dives, project devlogs and series.
  • Projects: open source tools I build and maintain.
  • Toolkit: small security tools that run entirely in your browser (nothing you paste into them leaves your machine), and review checklists you can tick off on screen or print.
  • Topics: all of the above, grouped by subject.
