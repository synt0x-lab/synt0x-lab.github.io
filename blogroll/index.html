Blogroll

Security blogs, news sites and newsletters I actually read, and why each is worth your time.

These are the security blogs, news sites and newsletters I read, each with one sentence on why. I only list sources I actually follow, so the list is short on purpose and changes when my reading does.

Want all of them in your feed reader at once? Import the OPML file: it contains every source below that publishes an RSS or Atom feed.

Research and offensive security

Google Project Zero feed
Root-cause analyses that walk from the bug all the way to a working exploit.
PortSwigger Research feed
Where new classes of web attacks, like request smuggling and cache poisoning, tend to be published first.
watchTowr Labs feed
N-day analyses of edge devices and enterprise software, built on patch diffing.
GitHub Security Lab feed
Variant analysis with CodeQL: how one bug turns into a query that finds its siblings.
Trail of Bits feed
Practical lessons from audits, fuzzing and building static analysis tools.
Doyensec feed
Application security research, with a lot of web and Electron vulnerabilities.
SpecterOps feed
Attack paths through Active Directory and identity systems, and the thinking behind BloodHound.
Orange Tsai feed
Posts rarely, but each one lays out a complete attack chain against widely used software.

Application security and cryptography

Filippo Valsorda feed
Go cryptography explained by one of its maintainers, including the reasoning behind API decisions.
Latacora feed
Short, opinionated cryptography and security advice that ends in a decision, not a survey.
Simon Willison on prompt injection feed
The most consistent running record of prompt injection: new attacks, failed defenses, and why the problem is hard.
Google Security Blog feed
Platform-scale defensive decisions and the reasons behind them.

News

The Hacker News feed
Fast daily coverage of new vulnerabilities, campaigns and breaches, useful for knowing what to look into first.

Newsletters

tl;dr sec newsletter feed
A weekly roundup of AppSec, cloud and AI security, with a short comment on each link.
Risky Bulletin newsletter feed
The week’s security news, condensed and filtered by people who know what matters.
CloudSecList newsletter feed
A curated list of cloud security research, tools and incidents.
Detection Engineering Weekly newsletter feed
The blue team side: detection logic, rule writing and how detection programs are run.
SANS NewsBites newsletter
A news summary with editor notes on which stories actually matter. Email only, so it is not in the OPML file.
